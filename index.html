Struttura cartelle di salvataggio

Percorso base: Z:\CONDIVISA\Preventivi\02_CLIENTI
La cartella base va selezionata una sola volta (poi resta memorizzata).

Compila nome cliente e tipo prodotto per vedere il percorso.

02_DDC sempre: anagrafica, preventivo, IVA, Enea, CT, visura, bollette, modello 12, personalizzati.
09_FINANZIAMENTO solo se presente Dati finanziamento o Modulo di consegna (allora ci finiscono anche identità, tessera, buste paga / cedolino / redditi). Altrimenti identità e tessera vanno in 02_DDC.

Chrome / Edge consigliati. La prima volta selezioni 02_CLIENTI; le volte successive il salvataggio è automatico.
